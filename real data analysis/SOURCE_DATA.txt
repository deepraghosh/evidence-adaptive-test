Frozen source data for the EA TCGA applications
=============================================

The four data files are unmodified copies of the local TCGA input files used
for Table S9. Filename prefixes distinguish the two studies. Their MD5 checksums
are recorded in INPUT_MD5.csv and verified by RUN_data_analysis.R. These frozen
bytes, rather than a changing repository branch, define the reproducibility
inputs. A specific upstream Git commit has not been established for these copies.

Data attribution: The Cancer Genome Atlas (TCGA), PanCancer Atlas studies;
distributed through cBioPortal's public DataHub.

Colorectal study:
https://github.com/cBioPortal/datahub/tree/master/public/coadread_tcga_pan_can_atlas_2018
  Upstream data_rppa.txt -> bundled coadread_data_rppa.txt
  Upstream data_clinical_patient.txt -> coadread_data_clinical_patient.txt

Stomach adenocarcinoma study:
https://github.com/cBioPortal/datahub/tree/master/public/stad_tcga_pan_can_atlas_2018
  Upstream data_rppa.txt -> bundled stad_data_rppa.txt
  Upstream data_clinical_patient.txt -> stad_data_clinical_patient.txt

Reference publications for study background
------------------------------------------
The Cancer Genome Atlas Network (2012). Comprehensive molecular characterization
of human colon and rectal cancer. Nature 487, 330--337.
The Cancer Genome Atlas Research Network (2014). Comprehensive molecular
characterization of gastric adenocarcinoma. Nature 513, 202--209.
Liu et al. (2018). Comparative molecular analysis of gastrointestinal
adenocarcinomas. Cancer Cell 33, 721--735.e8.

No live download is performed by the analysis code. Repository links are for
provenance and optional inspection; internet access is not needed to rerun.
